Project Title :-
Digital Payment Fraud Pattern Detector (UPI-Focused)

Problem Statement :-
With the rapid growth of UPI transactions in India, digital payment fraud has increased. 
Many fraud cases occur due to unusual transaction patterns such as late-night transactions, 
new receivers, or high-frequency transfers.

Objective :-
To build a Python-based system that analyzes UPI transaction behavior and 
assigns a fraud risk score based on suspicious patterns.

How It Works

The system:-
Reads transaction data from a CSV file
Applies rule-based risk analysis
Assigns a risk score to each transaction
Flags potentially suspicious transactions

Technologies Used
Python
Pandas

Future Enhancements:-
Add Machine Learning for anomaly detection
Integrate real-time monitoring
Build a web interface
