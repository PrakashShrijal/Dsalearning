# UPI Fraud Detection System (India-Focused)

## Overview
This project detects suspicious UPI transactions using rule-based logic and anomaly detection (Isolation Forest).

## Features
- Rule-based fraud detection
- ML-based anomaly detection
- Synthetic dataset generation
- Streamlit UI

## Technologies
Python, Pandas, Scikit-learn, Streamlit

## How to Run
pip install -r requirements.txt
python -m streamlit run app.py

## Use Case
Helps detect unusual transaction patterns such as:
- Late-night transactions
- High-frequency transfers
- New receivers

## Future Scope
- Real-time fraud detection
- Integration with banking APIs
